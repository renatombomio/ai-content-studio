# Coco — Mascot Reference

This document is the authoritative reference for generating Coco consistently across all contexts.
Any AI system generating Coco must derive its prompts from this document.

---

## Identity

**Name:** Coco
**Role:** Host of Cocoa Talk
**Species:** Muppet-inspired puppet (3D clay/felt texture, not photorealistic)
**Age appearance:** Adult, 28–33
**Gender:** Male

---

## Personality

| Trait | Expression |
|---|---|
| Calm | Speaks and moves slowly. Never rushed. |
| Curious | Eyes often slightly wide, head tilted. |
| Thoughtful | Pauses. Listens. Reflects before reacting. |
| Warm | Slight, genuine smile. Eyes carry expression more than mouth. |
| Never exaggerated | No wide gestures. No open-mouth excitement. |

---

## Fixed Physical Traits

These never change across any generation. They define Coco.

| Trait | Description |
|---|---|
| Skin | Deep brown, felt-like or clay texture. Not photorealistic human skin. |
| Beard | Short, neat, black beard. Always present. |
| Glasses | Round frames, dark (near-black). Always present. |
| Hoodie | Dark — near-black or very dark charcoal. Always present. |
| Mug | Teal/dark green ceramic. "Cocoa Talk" text visible on it. Almost always present. |
| Proportions | Puppet proportions — slightly larger head relative to body, expressive face. |
| Eyes | Large, Muppet-style — primary vehicle for emotion. |

---

## Variable Elements

These change between images to create variety while preserving identity.

**Poses:**
- Sitting at desk, writing in a notebook
- Reading a book (holding it, absorbed)
- Looking out a rain-covered window
- Sitting by a fireplace, mug in hand
- Chin on hand, thinking
- At a laptop (Apple)
- Simply sitting, holding mug, looking toward camera

**Facial expressions:**
- Contemplative (default — slightly soft gaze, gentle composure)
- Gentle smile (looking directly at viewer)
- Curious (head slightly tilted, eyes a little wider)
- Listening (attentive, still)
- Reflective (eyes downward or unfocused, inward)

**Camera angles:**
- Medium shot (most common — waist up, environment visible)
- Close-up (face and mug)
- Wide shot (Coco small in a large warm environment)

**Backgrounds / environments:**
Always from the Cocoa Talk visual language. Choose one or combine:
- Warm library / study room with bookshelves and soft lamp
- Rainy window — dark outside, warm inside
- Fireplace glow — amber light, blurred flames behind
- Wooden desk with notebook, pen, and mug
- Autumn — leaves visible through window or framing the scene

---

## Things Coco Never Does

- Angry expression or tense posture
- Open-mouth excitement or surprise
- Flashy clothing or accessories
- Pointing, waving, or large gestures
- Appearing in bright, saturated, or high-contrast environments
- Looking sad or distressed
- Appearing without glasses or hoodie

## Visual Language

All Coco images must use this palette and atmosphere:

| Element | Value |
|---|---|
| Near-black brown | `#1C0F07` |
| Dark red | `#6B1A1A` |
| Burgundy | `#8B2E2E` |
| Warm red | `#A03030` |

Lighting: always warm, amber-toned, soft. Single point source (lamp or fireplace). Never flat studio lighting.

## Brand Context

Coco is not a cartoon character. Not a mascot in the commercial sense.

Coco is the quiet host — the presence that holds the space Cocoa Talk creates.

Coco never sells anything. Never shouts. Never performs.

Coco just shows up, holds the mug, and creates the feeling that it is safe to think slowly here.
